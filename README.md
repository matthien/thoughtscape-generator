# thoughtscape generator

Type in a Letterboxd and/or Goodreads username and see your reviews laid out
on a cutting mat, the way [matt's thoughtscape](https://github.com/matthien/thoughtspace)
does. Nothing is stored and there's no account: the feeds are fetched on
request and rendered straight onto the canvas.

The canvas, cards, detail view and ruler are copied from the main thoughtscape
repo. They're kept as close to identical as possible so fixes can be carried
across by copying the file.

Next.js, no database. `npm install`, then `npm run dev`.
